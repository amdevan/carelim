    27→## API Contracts
    28→- `GET /api/doctors` → `Doctor[]` with `department` included. Doctor: `{id,name,email,phone,gender,qualification,specialization,departmentId,licenseNumber,experience,consultationFee,commissionPct,rating,workingDays,startTime,endTime,status,department:{id,name,color}}`
    29→- `GET /api/appointments?date=YYYY-MM-DD&doctorId=&status=` → `Appointment[]` with patient+doctor.department. Appointment: `{id,tokenNo,patientId,doctorId,departmentId,date,time,type,reason,status,fee,patient:{...},doctor:{...,department:{...}}}`
    30→- `POST /api/appointments` body: `{patientId,doctorId,date,time,type,reason,fee,status}` → created appt.
    31→- `PATCH /api/appointments/[id]` body: `{status:"checked-in"|"in-consult"|"completed"|"cancelled"}` → updated.
    32→- `GET /api/medicines` → `Medicine[]` with supplier. Medicine: `{id,name,genericName,category,manufacturer,batchNo,expiryDate,stockQty,reorderLevel,unitPrice,salePrice,barcode,location,status,supplier:{...}}`
    33→- `POST /api/medicines` body: `{name,genericName,category,manufacturer,batchNo,expiryDate,stockQty,reorderLevel,unitPrice,salePrice}`
    34→- `GET /api/invoices?status=` → `Invoice[]` with patient+items. Invoice: `{id,invoiceNo,patientId,type,subtotal,discount,tax,total,paid,due,status,paymentMethod,date,patient:{...},items:[]}`
    35→- `POST /api/invoices` body: `{patientId,type,subtotal,discount,tax,total,paid,due,status,paymentMethod,items:[{description,qty,rate,amount}]}`
    36→- `PATCH /api/invoices/[id]` body: `{paid,status}` to record payment.
    37→- `GET /api/lab-tests?status=` → `LabTest[]` with patient. LabTest: `{id,testCode,patientId,testName,category,doctorId,status,result,referenceRange,unit,fee,orderedAt,completedAt,patient:{...}}`
    38→- `POST /api/lab-tests` body: `{patientId,testName,category,fee,doctorId}`.
    39→- `PATCH /api/lab-tests/[id]` body: `{status,result,referenceRange,unit}` — set status to "approved" to approve.
    40→- `GET /api/staff` → `{staff: Staff[], departments: Department[], prescriptions: Prescription[]}`. Staff: `{id,name,email,phone,role,department,designation,salary,joinDate,status,attendance:[]}`. Prescription: `{id,code,patientId,doctorId,diagnosis,symptoms,vitals,advice,followUp,createdAt,patient:{...},doctor:{...},items:[]}`
    41→- `GET /api/reports` → `{totalRevenue,totalCollection,totalDue,revenueByType,doctorPerf:[{name,patients,revenue}],monthlyRevenue:[{month,revenue,collection}],patientCount,appointmentCount}`
    42→- `GET /api/audit-logs` → `AuditLog[]` `{id,user,action,module,detail,ip,createdAt}`
    43→- `GET /api/settings` → `{key:value}` object. `PUT /api/settings` body: `{key:value,...}`
